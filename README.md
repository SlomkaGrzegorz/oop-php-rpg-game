# PHP OOP RPG Game

A console RPG game written in PHP using object-oriented programming.
The player selects a character and then explores a dungeon, encountering enemies, treasures, and random events.

## Project Description

**PHP OOP RPG Game** is a CLI-based application designed to demonstrate the practical application of **OOP principles in PHP** in the form of a simple role-playing game.

Gameplay involves:
- the user selecting a character,
- moving around the dungeon,
- reacting to random events (combat, treasures, traps),
- managing the character's state during the game.

The project is educational in nature and provides a solid foundation for further expansion (e.g., new character classes, an equipment system, and enhanced combat).

## Requirements
PHP 8.0 or later
CLI environment
Composer

## Launching the application

### 1. Cloning the repository
git clone https://github.com/SlomkaGrzegorz/oop-php-rpg-game.git<br>
cd oop-php-rpg-game<br>
composer dump-autoload (if you don't have a composer you need to install it)<br>
php bin/game.php
